# 🤖 NovaMart AI Agent

An AI-powered sales analytics application that lets users ask
business questions in natural language and receive data-driven
answers and visual insights.

## 🚀 What I Built

NovaMart AI Agent connects:

User
  ↓
React Web App
  ↓
Node.js Backend
  ↓
Microsoft Foundry AI Agent
  ↓
Microsoft Fabric / Power BI Semantic Model
  ↓
Business Insights + Dynamic Visualizations

## 🧠 Key Capabilities

- Natural-language sales analytics
- Microsoft Foundry AI Agent
- Power BI / Fabric Semantic Model integration
- Governed business logic and measures
- Dynamic charts and visualizations
- Backend agent integration
- OAuth / identity passthrough exploration
- End-to-end request/response handling

## 🛠️ Technology Stack

- React
- Node.js
- Microsoft Foundry

- Git / GitHub

### Request Flow

1. User asks a sales question through the React application.
2. The request is handled by the Node.js backend.
3. Microsoft Foundry's NovaMart AI Agent processes the request.
4. Fabric IQ provides access to the connected semantic model.
5. The agent uses the semantic model and defined business logic to answer.
6. The response is returned to the web application.
7. Dynamic visualizations can be presented alongside the answer.

## 🎯 Why I Built This

I wanted to explore how AI Agents can be combined with
enterprise analytics and semantic models to create a more
natural way of interacting with business data.
